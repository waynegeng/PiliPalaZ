自动测试覆盖：

- 双指张开/捏合切换裁剪/自动、阈值防抖、单次手势限制、锁定状态和非全屏状态。
- Flutter 实际双指事件在禁用自由缩放时仍可识别，连续手势可以分别切换尺寸。
- 禁用全向旋转时主动解除横屏锁定；退出页面、重复操作、平台请求尚未完成时取消旧的延迟旋转任务。
- 应用横屏适配与播放器旋转设置的恢复规则。
- 纯净首页不挂载推荐分栏，设置立即切换，重复点击首页刷新不会访问未初始化的推荐控制器。
- 搜索框点击不跳转，空白输入不提交，中文及特殊字符直接传入结果页，返回保留输入，横屏窄窗口布局。

设备验收（自动测试不替代 Android/iOS 原生方向与媒体播放验证）：

1. 播放一个宽高比不同于屏幕的视频，进入全屏，双指张开后尺寸菜单显示“裁剪”；下一次捏合后显示“自动”。锁定控件后重复操作，尺寸不应改变。
2. 检查单指进度、亮度、音量手势；检查自动旋转形成的临时全屏与按钮进入的全屏。
3. 分别开启/关闭“全向旋转”和“横屏适配”，使用全屏按钮、播放器返回按钮及系统返回退出。回到首页并等待超过两秒，屏幕方向应遵循应用横屏适配设置。
4. 快速反复进入/退出全屏，再离开播放页；对直播页重复退出操作。检查是否残留横屏锁定或隐藏的系统栏。
5. 从设置进入“首页设置 → 首页”，开启“纯净首页”。返回首页、重启应用、重复点击首页导航：仅显示居中搜索框，不出现推荐分栏。
6. 点击搜索框原地输入，按键盘搜索/回车及右侧箭头分别提交；确认直接进入搜索结果，返回保留输入。关闭“纯净首页”后原首页恢复。

7. 在动态标签页中重排五个标签、逐个隐藏直到只剩一个，确认不能全部隐藏；选择默认标签后重启验证。隐藏 Up 后 UP 栏和筛选应消失，重新开启恢复原位置。
8. 投稿的封面、标题、作者、统计与首页同布局；点击播放和作者入口、刷新和分页可用。检查平板及窄屏，缺失信息不显示虚假的零。
9. 上滑内容隐藏标签顶栏，下滑立即恢复；切换标签、返回顶部恢复。UP 侧栏滚动、横向切页和程序滚动不应误触发隐藏，关闭开关后顶栏常驻。
10. 反复打开标签编辑并保存，确认无下标越界、失效的 UP 筛选监听；检查五类设置保存后重启仍保留。
